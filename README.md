# Segundo Cérebro: Music Mood & Data Science 🎵🧠

Este projeto foi desenvolvido como parte do Desafio de Projeto da DIO. O objetivo foi criar um "Segundo Cérebro" usando o Google NotebookLM para entender a interseção entre Inteligência Artificial, Música e Experiência do Cliente.

## 🎯 Tema e Objetivo
**Tema:** O impacto da música na mudança de humor sob a ótica da Ciência de Dados e CX.
**Objetivo:** Entender como os algoritmos das plataformas de streaming (como o Spotify) analisam os dados das músicas para detectar emoções e mudar o humor das pessoas, focando na Experiência do Cliente.

## 💬 Conversa com o Cérebro
Aqui estão algumas das interações que tive com o assistente:

**Pergunta 1:** Quais são os principais dados que os algoritmos analisam para entender a emoção?
**Resposta:** O assistente explicou perfeitamente sobre o espaço "Valência-Energia" (onde Valência mede a positividade da música) e como filtros colaborativos e processamento de linguagem natural (NLP) são usados. *(Veja o print nos arquivos do repositório)*.

**Pergunta 2:** Como a distribuição de Boltzmann introduz aleatoriedade controlada para evitar o cansaço do usuário?
**Resposta:** Ele explicou que usar algoritmos puramente determinísticos cansa o usuário. A distribuição de Boltzmann adiciona uma "aleatoriedade controlada", permitindo que o usuário descubra músicas novas sem sair da vibe que deseja. Isso aumenta muito a retenção e satisfação (CX).
